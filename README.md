# Master Blacklist Project

This project organizes blocklists into separate categories for different types of threats and unwanted content.
Each category has its own directory containing:
- `hosts`: Final blocklist file ready for use (format: 0.0.0.0 domain per line).
- `README.md`: Category-specific information (sources, usage, notes).
- `sorce.txt`: List of source URLs (one per line) for quick download.
- `scripts/`: Python scripts for processing and generating the blocklist (with raw/ and result/ subdirectories).

## Categories
- ads
- tracking
- malware
- phishing
- ransomware
- spam
- adult
- gambling
- dating
- bypass
- combined (security): merges ads, tracking, malware, phishing, ransomware, spam into a single blocklist

## Usage
For each category, use the Python scripts in the `scripts/` directory to process raw sources (from sorce.txt or manually placed in scripts/raw/) and generate the final blocklist in the `hosts` file.
The blocklist files are in a format suitable for DNS-based blockers (e.g., Pi-hole): one domain per line, optionally prefixed with `0.0.0.0`.

## Maintenance
Update the sources in sorce.txt as needed and re-run the scripts to regenerate the blocklist.
Each category is independent; updating one does not affect others.
To update the combined blacklist, regenerate the six category blocklists and combine them (or update the combined blacklist directly).

## Note
This is the workspace for the Master Blacklist project. The actual blocklists are generated by the scripts and stored in each category's `hosts/` directory.
